# Настройка RouterAI

Откройте **Настройки → RouterAI** и укажите обычный RouterAI API key, модель классификации и модель freshness. Master Key не требуется. Base URL зафиксирован на `https://routerai.ru/api/v1`, а идентификаторы моделей редактируются.

Кнопка «Проверить подключение» вызывает список моделей. Freshness‑проверка включает web plugin, предпочитает официальные источники и валидирует JSON через Zod. До запроса содержимое проходит secret redaction. Для контроля расходов доступны лимиты проверок и concurrency.
