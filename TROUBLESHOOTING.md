# Решение проблем

- **Неверный api_id/api_hash** — проверьте, что `api_id` состоит из цифр, а `api_hash` содержит 32 hex‑символа.
- **Код истёк** — запросите его повторно; код и пароль никогда не сохраняются.
- **FloodWait** — дождитесь показанного времени. Checkpoint сохранён.
- **RouterAI 401/402** — проверьте ключ и баланс через «Проверить подключение».
- **Неизвестная модель** — укажите существующий model ID в настройках.
- **База не открывается** — закройте другие копии SavedAtlas; сделайте backup перед восстановлением.
- **macOS блокирует unsigned app** — используйте контекстное меню «Открыть» для локально собранного DMG. Публичное распространение требует подписи и нотарификации.
- **Вложение не анализируется** — media provider в этой версии не реализован; кнопка анализа явно отключена. Текст и подписи продолжают индексироваться.

«Скопировать технические детали» должен использовать только redacted error; raw stack trace в обычном UI не показывается.
